# Game State

Current version: **0.2.0**

## Built
- Unity 2D project setup (Force Text serialization, Visible Meta Files, 2D editor mode).
- `HomeScreen` scene (first scene in the build): title, New Game, Continue, Settings, Quit, and the version label.
  - New Game and Continue are disabled until runs and saved games exist.
  - Settings panel: master volume, fullscreen, resolution, Back. Saved with PlayerPrefs through `GameSettings`.
  - The scene is generated by `HomeScreenSceneBuilder` (menu: KyubPon > Rebuild Home Screen Scene). Change the layout in that script, because rebuilding replaces the scene.
- Input goes through Unity's Input System package (`com.unity.inputsystem`). Menus work with mouse, keyboard (arrows + Enter), and controller using Unity's default UI actions.
- Press Start 2P pixel font in `Assets/Game/Fonts/PressStart2P/` (see `docs/Credits.md`).
- `DropScreen` scene and script from 0.1.0. No longer in the build; kept until the opening animation replaces it.

## Known issues
- Fullscreen and resolution only take effect in a built game, not inside the Unity Editor.
- Settings does not yet match the full plan in CLAUDE.md section 6: no separate Music/SFX sliders or Audio Mixer, no VSync or frame-rate cap, no "Keep these settings?" prompt, no quality presets.
- Menu text is written directly in the scene and scripts. It should move to Unity's Localization package (needs that package added).
- UI text uses the legacy `Text` component, not TextMeshPro.
- No automated tests yet (there is no game logic to test so far).
